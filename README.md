## 📌 About The Community

The **AWS Student Builder Group (AWS SBG)** at **St. Andrews Institute of Technology and Management (SAITM)** is an official student-led engineering initiative aligned with the global Amazon Web Services (AWS) ecosystem. 

Our mission is to bridge the gap between academic curricula and production cloud architectures through hands-on labs, hackathons, and collaborative open-source shipping.

---

## ⚡ Core Builder Tracks

<table>
  <tr>
    <td width="50%">
      <h3>☁️ Cloud Computing & Serverless</h3>
      <p>Master AWS core services like EC2, S3, IAM, DynamoDB, VPC, and event-driven functions using AWS Lambda.</p>
    </td>
    <td width="50%">
      <h3>🧠 Generative AI & Machine Learning</h3>
      <p>Construct autonomous agents and RAG pipelines powered by Amazon Bedrock, SageMaker, and foundation models.</p>
    </td>
  </tr>
  <tr>
    <td width="50%">
      <h3>🔄 DevOps & Cloud CI/CD</h3>
      <p>Automate deployments with GitHub Actions, Docker containers, and AWS CDK Infrastructure as Code (IaC).</p>
    </td>
    <td width="50%">
      <h3>🏆 Hackathons & Certifications</h3>
      <p>Participate in Smart India Hackathon (SIH), study groups for AWS Cloud Practitioner and Solutions Architect exams.</p>
    </td>
  </tr>

## 🛠️ Tech Stack

* **Design Pattern:** Bento Grid UI, Glassmorphism, Responsive Mobile Drawer
* **Typography:** [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
