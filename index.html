WHAT WE DO

Our Core Domains

We focus purely on active building — spanning modern software engineering, AI, and cloud architectures.

Cloud Computing

Master AWS core services like EC2, S3, IAM, and Lambda through hands-on deployment and architecture labs.

Artificial Intelligence

Explore GenAI and ML tools on AWS, building intelligent applications with Amazon Bedrock, SageMaker, and LangChain.

DevOps & CI/CD

Learn GitHub Actions, AWS CodePipeline, and Docker for automated cloud deployments and scalable infrastructure.

Full Stack Dev

Build scalable, cloud-native web apps and serverless APIs from modern frontends to DynamoDB and PostgreSQL databases.

Certification Prep

Structured study groups, exam vouchers, and practice materials for AWS Certified Cloud Practitioner & Solutions Architect exams.

Open Source & Hackathons

Collaborate on real student initiatives, participate in Smart India Hackathon (SIH), and build portfolio-ready cloud projects.

CLUB FORMATION

Why We Started

The AWS Student Builder Group (formerly AWS Cloud Club) at St. Andrews Institute of Technology and Management (SAITM) was formed to establish an official, structured cloud and AI-focused student community directly aligned with the global AWS ecosystem.

  • Provide hands-on cloud learning beyond standard classroom theory
  • Foster a collaborative, peer-driven builder culture
  • Enable students to build and ship real-world production projects
  • Build an active bridge connecting students with AWS leaders, faculty, and industry veterans
